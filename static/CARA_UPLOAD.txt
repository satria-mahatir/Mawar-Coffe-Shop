📤 CARA 1: UPLOAD VIA FTP/HOSTING PANEL
════════════════════════════════════════════════════════════════════════════════

1. Masuk ke cPanel atau File Manager hosting Anda
2. Buka folder public_html atau folder website Anda
3. Upload folder "static" dengan struktur yang sama

Struktur akhir di server:
   public_html/
   ├── index.php (dinamis - tetap ada)
   ├── admin/
   ├── config/
   ├── includes/
   ├── pages/
   ├── assets/ (PHP version)
   └── static/ ← Upload folder ini lengkap dengan struktur
       ├── index.html
       ├── assets/
       │   ├── css/
       │   ├── js/
       │   └── images/
       └── CARA_UPLOAD.txt

4. Akses via: https://yourdomain.com/static/index.html

📞 BANTUAN & TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Masalah: Gambar tidak muncul
Solusi:
   • Pastikan folder assets/images/ ter-upload lengkap
   • Check browser console (F12 → Console)
   • Pastikan path menggunakan assets/images/ bukan /images/

Masalah: CSS tidak diterapkan / Layout berantakan
Solusi:
   • Pastikan assets/css/style.css ter-upload
   • Clear browser cache (Ctrl+Shift+Delete)
   • Check browser console untuk CSS load errors

Masalah: JavaScript tidak berfungsi
Solusi:
   • Pastikan assets/js/main.js ter-upload
   • Check browser console untuk JS errors
   • Pastikan Leaflet JS CDN accessible

Masalah: Video hero tidak play
Solusi:
   • Check apakah file video ada di assets/images/
   • Pastikan format webm support di browser
   • Coba di browser Chrome/Firefox terbaru
